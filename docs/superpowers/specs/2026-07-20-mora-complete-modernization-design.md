# Mora 完整改造设计

日期：2026-07-20

## 目标

在保留 Vue 3、Toast UI Editor、Tauri 2、Rust 和现有 MDXNote `.mdx` v1 文件兼容性的前提下，完成可靠性、架构、安全、测试、核心笔记能力和桌面使用体验的整体升级。

## 范围

本次改造包含：

- 修复图片粘贴、打开、预览、保存、重复写入和对象 URL 泄漏。
- 支持图片与普通附件的选择、拖放、粘贴、包内保存和元数据维护。
- 修复全局快捷键劫持输入框问题。
- 增加关闭、新建、打开时的未保存保护，以及本地自动恢复草稿。
- 加固 `.tmp + .bak` 保存流程、崩溃恢复、ZIP 路径、版本和体积校验。
- 拆分前端单文件职责与 Rust 文件格式职责。
- 增加前端单元测试、Rust 单元测试、Lint、格式化和持续验证脚本。
- 配置 CSP，并移除对 Toast UI 私有事件和已废弃编辑命令的依赖。
- 增加标签、全文搜索、历史版本、Markdown 导出和 PDF 打印导出。
- 增加深色模式、字体、字号、行高、阅读宽度、响应式窗口和键盘可访问性。
- 增加可见状态通知、当前文件路径和明确的错误反馈。

不包含云同步、多人协作和加密；这些能力继续保留扩展点，但不作为本轮完成条件。

## 总体方案

采用渐进式改造，不重写编辑器内核：

1. 先建立可测试的纯函数和 Rust 文件格式边界。
2. 修复数据正确性和未保存保护。
3. 拆分前端状态、编辑器、资源、快捷键、搜索和设置模块。
4. 在稳定边界上增加附件、历史、搜索、导出和偏好设置。
5. 最后完成界面、无障碍和构建体积优化。

## 前端架构

前端按职责拆分：

- `src/types/mdx.ts`：Manifest、Metadata、Resource、Note 和保存请求类型。
- `src/composables/useDocument.ts`：当前路径、标题、正文、元数据、脏状态、新建、打开和保存。
- `src/composables/useEditor.ts`：Toast UI 生命周期、模式切换、选择区和官方命令调用。
- `src/composables/useResources.ts`：对象 URL、图片、附件、拖放、保存队列和资源清理。
- `src/composables/useShortcuts.ts`：应用级快捷键；输入框和可编辑控件保留原生行为。
- `src/composables/useAutosave.ts`：草稿快照、恢复、清理和窗口关闭保护。
- `src/composables/useSearch.ts`：当前文档查找替换和本地全文索引查询。
- `src/composables/usePreferences.ts`：主题和阅读设置持久化。
- `src/components/`：菜单、目录、查找栏、资源面板、标签栏、状态栏、设置面板和历史面板。

组件通过明确的 props、事件和 composable API 交互，不直接查询 Toast UI 内部 DOM；仅编辑器适配层可以接触 Toast UI 实例。

## 资源数据流

每个打开的文档拥有独立资源会话：

1. 打开 `.mdx` 后，Rust 返回正文、元数据和资源索引。
2. 前端按需读取包内资源并创建对象 URL。
3. 显示层将 Markdown 中的 `assets/...` 和 `attachments/...` 映射为对象 URL，但持久化正文始终保留相对路径。
4. 粘贴或拖入资源时生成 UUID 文件名，更新保存队列和元数据。
5. 保存成功后资源转为已持久化状态，避免重复写入。
6. 切换文档或退出时统一撤销对象 URL 并清空会话。

Rust 只接受规范化的 `assets/<name>` 或 `attachments/<name>` 路径，拒绝绝对路径、父目录、盘符、反斜杠和目录项。

## 文件格式与安全保存

继续写入 `formatVersion: 1.0.0`，并兼容已有 v1 文件。新增元数据字段均提供默认值。

打开文件时验证：

- 固定格式名、受支持的语义版本、`single-note` 包类型、UTF-8 和非加密状态。
- Manifest 中的正文和元数据路径必须是安全的包内相对路径。
- ZIP 条目数量、单条解压大小和总解压大小不超过配置上限。
- 必需文件只允许一个，资源条目名称必须安全。

保存流程：

1. 在目标目录写入唯一临时文件并刷新到磁盘。
2. 验证新 ZIP 可以重新打开。
3. 将旧文件替换为备份，再原子替换目标文件。
4. 替换失败时恢复备份；恢复失败时保留临时文件和备份，并返回包含路径的错误。
5. 启动时发现残留备份或草稿时向用户提供恢复选项。

历史版本以 `history/<timestamp>.json` 保存正文、标题和元数据快照；限制数量，采用先进先出清理。

## 搜索、标签与导出

- 标签保存在 `meta.json.tags`，编辑后随文档保存。
- 全文索引保存在 Tauri 应用数据目录，记录路径、标题、标签、摘要、修改时间和规范化正文；打开或保存笔记时更新。
- 搜索结果展示标题、路径、标签和命中摘要，点击后打开对应笔记。
- Markdown 导出生成 `.md` 和同名资源目录，重写资源相对路径。
- PDF 导出使用系统打印对话框和专用打印样式，避免引入大型 PDF 渲染依赖。

## 未保存保护与自动恢复

- 新建、打开和关闭时统一调用离开守卫。
- 用户可以选择保存、放弃或取消。
- 编辑后按防抖间隔将标题、正文、路径和元数据写入应用数据目录草稿。
- 正常保存后删除对应草稿。
- 启动时若草稿比源文件新，则显示恢复提示。

## 界面设计

保持紧凑桌面软件布局，强化 Mora 的纸墨感，但不采用仿纸纹理：

- 浅色使用偏冷纸白和墨蓝，深色使用深靛灰和低饱和青色强调色。
- 编辑正文保持中性，品牌表达集中在标题、状态反馈和少量图标细节。
- 支持系统主题、手动浅色和深色三种模式。
- 设置项包含字体、字号、行高、内容最大宽度和目录显示。
- 窗口最小宽度与 CSS 一致，小窗口自动收起目录和次要菜单。
- 所有按钮、菜单、目录项和对话面板支持键盘焦点和可见 `:focus-visible`。
- 尊重 `prefers-reduced-motion`。

## 错误处理

- 用户可恢复错误使用可见通知或对话框，不仅写入控制台。
- Rust 错误映射为稳定错误码和中文消息，前端根据错误码决定是否提供重试、恢复或移除最近文件。
- 保存、导出和索引失败互不混淆；索引失败不应导致文档保存失败。

## 测试策略

Rust 单元测试覆盖：

- Manifest 校验和版本边界。
- ZIP 路径穿越、重复条目和体积限制。
- 新建、打开、保存、资源保留和历史轮转。
- 安全保存成功、替换失败和备份恢复。
- Markdown 导出和全文索引数据生成。

前端测试覆盖：

- 快捷键目标判断。
- Markdown 资源路径与对象 URL 双向映射。
- 脏状态、离开守卫和草稿恢复。
- 查找替换、标签和偏好设置。
- 主要组件的键盘交互。

验收时必须执行：

- `npm test`
- `npm run lint`
- `npm run build`
- `cargo test --manifest-path src-tauri/Cargo.toml`
- `cargo check --manifest-path src-tauri/Cargo.toml`
- `npm run tauri -- build`

并通过人工桌面检查：中文输入法、图片粘贴、附件拖入、重复保存、关闭恢复、历史还原、搜索、导出、浅深色和 760px 窗口。

## 兼容与迁移

- 旧 `.mdx` 文件无需迁移即可打开。
- 缺少新增字段时使用默认值。
- 首次保存旧文件时仅补充必要元数据，不更改正文语义。
- 最近文件和偏好数据损坏时回退为空列表或默认设置，不阻止应用启动。

1. 测试基础、资源链路、快捷键、未保存保护和安全保存。
2. 模块拆分、ZIP 加固、CSP、Lint 和构建分包。
3. 附件、标签、全文搜索、历史和导出。
4. 主题、排版偏好、响应式、无障碍和最终桌面验收。
