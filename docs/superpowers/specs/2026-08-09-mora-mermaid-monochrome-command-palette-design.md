# Mora Mermaid、阅读黑白主题与命令面板设计

**日期：** 2026-08-09
**状态：** 已实施

## 目标

在不改变 MDXNote 文件格式、规范 Markdown 单一权威来源和三种既有编辑视图的前提下，增加：

1. Mermaid 图表渲染，覆盖流程与结构、时序与计划、思维导图。
2. 面向长文阅读的黑白主题。
3. 覆盖既有全部菜单操作的命令面板。

## 已确认边界

- 编辑器能力优先使用 Milkdown/Crepe 的公开 API；只有核心缺失的部分才做小型补充。
- 黑白主题和命令面板由 Mora 自己实现，但必须复用既有偏好状态和菜单 action，不创建平行状态或第二套命令逻辑。
- Mermaid 只支持以下分类：
  - 流程与结构：流程图、状态图、类图、ER 图、需求图、C4、架构图、方块图。
  - 时序与计划：时序图、甘特图、时间线、用户旅程图。
  - 思维导图。
- 不实现可视化拖拽编辑、语法自动补全、图表模板库、拼音模糊搜索或独立 Preview renderer。
- `.mdx` 保存内容不变；图表始终以 `mermaid` 围栏代码块原文保存。

## 已交付范围

- Mermaid 仅渲染流程与结构、时序与计划和思维导图三类；其他 Mermaid 类型继续作为普通代码块显示。
- 仅源码模式显示围栏源码；所见即所得、源码加只读预览及打印使用同一 Mermaid 预览桥接。
- “阅读黑白”主题通过既有偏好持久化；`Ctrl+Shift+P` 命令面板列出并复用全部既有菜单 action。

## 方案选择

采用方案 1：通过 Crepe 现有代码块组件的公开 `renderPreview` 配置接入 Mermaid。

当前 `@milkdown/plugin-diagram` 的最高发布版本为 7.7.0，不能与项目的 Milkdown 7.21.3 兼容，因此不使用该插件，也不接触编辑器内部 DOM。

### Mermaid

新增固定版本的 `mermaid` 运行时。Mora 自己实现一个小型渲染桥接：

1. Crepe 的 CodeMirror 功能继续负责代码块的编辑、语言选择和预览开关。
2. `renderPreview(language, content, applyPreview)` 仅处理语言为 `mermaid` 的代码块。
3. 桥接调用 Mermaid 的公开 `render` API，创建预览元素并通过 `applyPreview` 交还现有代码块组件。
4. Mermaid 使用 `securityLevel: "strict"`；不允许图表源码注入 HTML 或脚本。
5. 非本期支持的 Mermaid 图类型保持普通代码块；解析或渲染失败时显示简明错误和原始代码，不改写 Markdown。

此路径自动覆盖：

- WYSIWYG 编辑器中的代码块预览；
- 垂直双栏右侧的只读 Milkdown 预览；
- 现有打印流程创建的临时只读 WYSIWYG 编辑器。

仅源码模式保留源代码编辑，不显示图表，符合既有视图定义。

### 阅读黑白主题

在现有 `ThemePreference` 中新增 `monochrome` 值，并通过 `usePreferences` 持久化。设置面板新增“阅读黑白”选项。

主题使用浅色阅读底、深灰正文和有限灰阶层级。重点保证：

- 正文、标题、链接、引用、代码块和表格的阅读对比；
- 选中态、悬停态与键盘焦点可辨识；
- Milkdown/Crepe 和 CodeMirror 使用同一组 CSS 变量；
- 语义错误和成功信息继续带有明确文字，不仅依赖颜色区分。

不修改浅色、深色和跟随系统的解析逻辑。

### 命令面板

新增一个局部 `CommandPalette.vue` 对话框。它只负责展示和调用命令，不拥有业务 action。

`App.vue` 保留既有文件、编辑、格式、插入、视图、关于六组计算菜单；命令面板从这些数组派生扁平列表，为每项补充分类名。菜单和面板调用同一个 `action`，并读取同一个 `disabled` 状态。

交互：

- `Ctrl+Shift+P` 打开面板；
- 输入按命令名称和分类进行不区分大小写的子串匹配；
- 上下方向键移动高亮项，Enter 执行可用项，Esc 关闭；
- 所有既有菜单操作均列出；当前不可执行的操作可见但禁用；
- 关闭后把焦点返回启动面板前的元素；不使用定时器或 DOM 查询补丁。

## 必要新增模块

| 模块 | 必要性 |
| --- | --- |
| Mermaid 预览桥接 | Crepe 只提供预览挂钩，不提供与当前版本兼容的 Mermaid 实现；删除后 Mermaid 只能显示为代码。 |
| `CommandPalette.vue` | 现有菜单没有搜索、键盘列表或模态焦点管理；删除后“全部命令可搜索执行”的验收项失败。 |

不新增 store、命令注册中心、编辑器节点类型或 Markdown 转换层。

## 测试与验证

- Mermaid 桥接：受支持类型可渲染；非支持类型、语法错误和异步失败保留源码并给出失败状态；WYSIWYG、垂直双栏预览和打印路径均使用同一桥接。
- 偏好设置：`monochrome` 可加载、保存和解析，主题变量覆盖阅读区与源码区。
- 命令面板：全菜单命令收录、筛选、禁用状态、键盘选择、关闭焦点恢复和 action 复用。
- 功能实现完成后运行 `npm test`、`npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml` 和 `npm run tauri -- build`。

## 本次不实现

- 图表拖拽编辑、模板库、自动补全、导出 SVG/PNG。
- Mermaid 的数据图、工程图、ZenUML 及实验性图表类型。
- 命令历史、可配置快捷键、拼音匹配、命令扩展机制。
- 调整 `.mdx` 格式、Rust command、资源保存或 AI 工作流。
