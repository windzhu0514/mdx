# Mermaid 查看器按钮提示设计

## 目标

为 Mermaid 图表查看器工具栏中的每个可操作控件增加鼠标悬停提示，让用户无需猜测图标用途，同时保留现有键盘与读屏体验。

## 当前行为

工具栏按钮已有 `aria-label`，但没有可见的鼠标悬停提示。图标含义相近，其中“适应视图”和“全屏查看”尤其容易混淆。

## 方案

直接为现有控件增加原生 `title` 属性，不新增 Tooltip 组件、依赖或样式。提示文字与 `aria-label` 使用相同语义，避免鼠标提示与无障碍名称不一致。

| 控件 | 提示文字 |
| --- | --- |
| 上一张图按钮 | 上一张图 |
| 下一张图按钮 | 下一张图 |
| 缩小按钮 | 缩小 |
| 缩放比例选择器 | 缩放比例 |
| 放大按钮 | 放大 |
| 适应视图按钮 | 适应视图 |
| 全屏按钮（普通状态） | 全屏查看 |
| 全屏按钮（全屏状态） | 退出全屏 |
| 导出按钮 | 导出 PNG |
| 关闭按钮 | 关闭查看器 |

全屏按钮的 `title`、`aria-label` 随状态同步变化，使提示描述按钮点击后的动作。

## 实现范围

- 修改 `src/components/editor/MermaidViewer.vue` 中现有工具栏控件属性。
- 修改 `src/components/editor/MermaidViewer.test.ts`，覆盖全部提示文字和全屏状态切换。
- 不增加按钮，不改变缩放、适应视图、全屏、导出或关闭行为。
- 不新增 Tooltip 组件、依赖、全局状态或 CSS。

## 验收标准

1. 鼠标停留在每个工具栏按钮上时，浏览器显示对应原生提示。
2. 缩放比例选择器也显示“缩放比例”提示。
3. 全屏前提示为“全屏查看”，全屏后提示为“退出全屏”。
4. 所有控件继续保留准确的 `aria-label`。
5. Mermaid 查看器现有测试及项目构建、Rust 检查、Tauri 打包通过。

## 删减检查

本次只增加 HTML 属性和对应测试。删除任何新增属性都会使提示验收失败；无需新增模块、接口、依赖或通用 Tooltip 抽象。
