# Mora 黛蓝主题区分设计

## 目标

在保留“黛蓝”主题名称和深色主题定位的前提下，让它与“墨黑”形成一眼可辨的视觉差异，同时保持长时间编辑的舒适度。

## 视觉方向

采用“夜幕黛蓝”：提高背景明度与蓝色倾向，保持低饱和度。墨黑继续表现为接近黑色的青灰；黛蓝表现为层次清晰的蓝灰夜色。

核心色值：

| 角色 | 色值 |
| --- | --- |
| 主背景 | `#162334` |
| 编辑与表面 | `#1c2b3d` |
| 侧栏 | `#18283a` |
| 浮层 | `#24364b` |
| 主要文字 | `#e7edf3` |
| 强调色 | `#83add1` |

## 实现范围

- 只调整 `dai-blue` 对应的现有语义颜色令牌。
- 保持主题标识 `dai-blue` 和界面名称“黛蓝”不变。
- 根据核心色值补齐顶栏、侧栏弱背景、侧栏标题、输入框、控件、边框、次要文字、状态色、渐变和阴影令牌。
- 保留现有六主题机制、主题选择交互和组件结构。

## 不实现

- 不修改墨黑及四个浅色主题。
- 不新增组件、依赖、主题变体或配置项。
- 不调整字体、布局、间距和交互行为。

## 验收标准

1. 黛蓝主背景固定为 `#162334`，强调色固定为 `#83add1`。
2. 黛蓝与墨黑的主背景、表面、侧栏和强调色均不相同。
3. 黛蓝所有背景层保持蓝灰色相，并维持深色 `color-scheme`。
4. 现有六主题和主题选择测试继续通过。
5. `npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml` 和 `npm run tauri -- build` 均成功。

## 删减检查

本次只修改现有 CSS 令牌与回归测试。没有新增模块、接口、适配层或依赖；删除其中任一额外抽象不会影响验收，因此不引入额外抽象。
