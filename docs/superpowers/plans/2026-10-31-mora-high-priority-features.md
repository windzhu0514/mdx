# 墨笺高优先级功能实施计划

## 目标与约束

补齐系统文件打开、工作区文件管理、历史版本对比和搜索结果定位。保留当前未提交的中英文界面实现与 TODO 修改。中文展示“墨笺”，英文展示“Mora”，包名保持 `mora`。

正文继续由现有文档会话维护，编辑器只通过 Milkdown、ProseMirror 和 CodeMirror 公开 API 操作。不得引入第四种编辑视图、额外 Markdown renderer 或另一份可编辑正文。文件格式和 `.tmp + .bak` 安全保存规则保持兼容。

## 当前必须实现

- [x] 系统文件打开：Tauri 注册文件类型，首次启动和单实例后续请求统一接入现有打开链路；包含中文、空格、多文件、重复文件和无效参数测试。注册“打开方式”不强改系统默认应用。前端就绪前的文件请求应可排队，避免监听建立前丢失。
- [x] 工作区文件管理：新建文件与文件夹、重命名、移动、移入系统回收站、在资源管理器中显示。复用现有保存与 Markdown 资源搬迁能力，覆盖重名、路径越界、文件夹自包含移动、未保存文档、外部冲突及失败回滚。成功后同步文档路径、草稿、最近文件、会话、索引和文件监听；不得删除共享外置资源。
- [x] 历史版本对比：版本选择、只读预览、与当前内容的差异展示、确认恢复。必须处理快速切换版本或文档导致的异步旧响应；对比行为不修改当前正文。保留现有恢复资源和元数据语义。
- [x] 搜索定位：结果提供匹配上下文和高亮，点击后打开文档并定位相应匹配；支持已有三种视图，遵守规范 Markdown 与所见即所得文本的差异。定位使用打开后的当前内容，防止索引偏移过时或 Unicode 偏移单位不同造成错误。覆盖中文、重复命中、空结果和异步切换。

## 文件职责

- `src-tauri/tauri.conf.json`、`src-tauri/src/lib.rs` 及必要的文件打开模块：系统打开配置、请求排队和命令注册。
- `src-tauri/src/workspace.rs` 及必要的文件操作模块：受工作区边界约束的文件操作。新增模块仅用于隔离实际的系统文件操作职责，不创建通用适配层。
- `src/composables/useDocumentSession.ts`、`src/App.vue`、`src/components/WorkspaceSidebar.vue`：文件操作与现有文档会话、保存保护的衔接。
- `src/components/HistoryPanel.vue`、必要的差异展示辅助函数和 `src/App.vue`：历史读取、展示及确认恢复。
- `src/components/LibraryPanel.vue`、`src/types/library.ts`、编辑器句柄与各编辑器组件：搜索匹配展示和公开 API 定位。
- 相应测试、`README.md`、`TODO.md`：回归和当前使用说明。

## 条件扩展与本次不实现

只有实测现有索引无法满足规模要求时才替换搜索引擎；只有实际文件规模超出当前扫描限制时才加入新的目录监听或索引服务。本次不增加云同步、自动冲突合并、知识图谱或插件框架。

## 实施与验证

每条链路先写失败测试并运行，再实现与回归。新增系统依赖优先选择 Tauri 官方插件或已使用库，明确其必要性。完成后运行前端完整测试、发布脚本测试、Rust 相关测试、Lint、格式检查，以及 `npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml`、`npm run build:exe`。文件关联还需核对构建出的安装包配置；未实际安装或未在目标系统操作的行为须明确标为未验证。不得提交、发布、注册系统默认应用或清理用户原有改动。
