## 独立环境验收待办

以下项目需在另一台 Windows 电脑或独立虚拟机执行；当前开发机上的安装验证不能代替这些结果。

1. 无 Node、Rust、开发工具的普通用户环境安装 MSI / NSIS，首次启动正常，WebView2 缺失时能完成安装。
2. 新建中文文档，粘贴图片、添加附件，保存 `.mdx` 后关闭、重开，核对正文、图片、附件完整。
3. 修改已有笔记后异常退出，验证草稿恢复；保存中断备份恢复只处理缺失原件，保留不支持格式的现有文件。
4. 从公开 0.1.2 升级至 0.1.3，验证最近文件、工作区、草稿和笔记资源保持完整。
5. 真实在线更新链路：发现版本、下载、签名校验、处理未保存文档、安装重启。草稿或预发布版本可能不会由默认 latest 端点返回。
6. 卸载后确认用户文档未被删除；重新安装可以继续打开旧笔记。
